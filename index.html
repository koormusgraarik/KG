Tootmise jälgimine Sisestus

Aeg on kogu partii kohta tundides: 1,6 = 1,6 h. Tüki kohta: 0,2/tk korrutatakse kogusega. Minutites: 45 min. Salvestub Enteri või väljast lahkumisel.

Grupid

Grupi nime muutmine muudab selle kõigil grupi pinkidel. Nooltega muudad gruppide järjekorda Nädalad- ja Koormus-vaates. Uue grupi teed, kui valid pingi juures „+ uus grupp…”.

Omad pingid

h-MAX = pingi töötunnid nädalas (nagu Exceli Koormus lehel); pühadega nädalal arvestatakse vähem. Sama „Rida” nimega pingid liidetakse nädalakoormuses üheks reaks (nt F205-7/212-4), „Grupp” moodustab Summa-ploki. Vaikenormi kasutatakse prognoosis, kui etapil endal aega pole. „Ei ole etapp" jätab koodi järgmisel impordil marsruudist välja.

Allhanked

Tarneaeg tööpäevades — sellega arvestab prognoos. Tegelikku keskmist näed vahelehel Koormus.

Kasutajad

Uued kontod: Supabase → Authentication → Users → Add user (Auto Confirm), nt mart@kg.local — sisse saab siis logida lihtsalt nimega „mart”. Roll kiosk = tsentraalpunkti seade. Töölised ja PIN-id: lehel Sisestus → Töölised.
