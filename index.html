Tootmise jälgimine

Aeg on kogu partii kohta. Sisesta minutid (90), tunnid (1.5h) või minutid tüki kohta (3/tk korrutatakse kogusega). Salvestub Enteri või väljast lahkumisel.

Pingid

Maht = töötunde päevas. Allhanke puhul arvestatakse aega tarnepäevades ja mahtu ei piirata. „Ei ole etapp" jätab koodi järgmisel impordil marsruudist välja (nt märked nagu LK). Vaikenormi kasutatakse prognoosis, kui etapil endal aega pole.

Kasutajad

Uued kontod: Supabase → Authentication → Users → Add user (Auto Confirm). Profiil tekib automaatselt, siin saad nime ja rolli muuta.
