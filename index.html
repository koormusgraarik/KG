Tootmise jälgimine

Aeg on kogu partii kohta tundides: 1,6 = 1,6 h. Tüki kohta: 0,2/tk korrutatakse kogusega. Minutites: 45 min. Salvestub Enteri või väljast lahkumisel.

Omad pingid

Maht = töötunde päevas (2 vahetust = 16). Vaikenormi kasutatakse prognoosis, kui etapil endal aega pole. „Ei ole etapp" jätab koodi järgmisel impordil marsruudist välja.

Allhanked

Tarneaeg tööpäevades — sellega arvestab prognoos. Tegelikku keskmist näed vahelehel Koormus.

Kasutajad

Uued kontod: Supabase → Authentication → Users → Add user (Auto Confirm). Profiil tekib automaatselt, siin saad nime ja rolli muuta.
